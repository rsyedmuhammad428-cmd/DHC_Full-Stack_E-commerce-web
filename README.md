# E-Commerce Web Internship

A responsive multi-page e-commerce website built with HTML, CSS, and JavaScript.

## Overview

This project is a front-end e-commerce website with a custom homepage, product listing page, product detail page, and shopping cart page. The layout is designed to feel modern, responsive, and interactive across desktop, tablet, and mobile devices.

## Features

- Responsive header and footer with shared branding
- Homepage with hero banner, deals, category sections, quote form, services, and region suppliers
- Product listing page with:
  - category filtering
  - brand filtering
  - price filtering
  - sort options
  - grid and list view
- Product detail page with:
  - dynamic product content
  - thumbnail image switching
  - tab-style content sections
  - add to cart and save for later actions
- Cart page with:
  - quantity updates
  - remove item action
  - coupon interaction
  - checkout button
- Local storage support for cart and saved items

## Project Structure

- `index.html` : homepage
- `products.html` : product listing page
- `product-detail.html` : single product detail page
- `cart.html` : shopping cart page
- `style.css` : all website styling and responsive rules
- `script.js` : shared interactions and product/cart logic

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.

You can also use a local live server in VS Code for easier development.

## Notes

- This is a front-end project only.
- Product, cart, and filter data are handled on the client side.
- Cart and saved items are stored in browser local storage.
